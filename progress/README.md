# Progress / look archive

Reference screenshots kept to remember how the game looked at each stage (not used
by the game — this folder has a `.gdignore` so Godot skips it).

- `2d_*.png` — the **2D Synty-billboard** version: top-down TileMap floors with
  Synty 3/4 billboards (overworld, all 13 levels, and the 2D Gimme Dat Spoon table).
  This is the look just before the 3D migration.
- `3d_*.png` — the **3D migration** (in progress): real Synty 3D meshes, environments,
  and a 3/4 camera (church level + Gimme Dat Spoon set-piece).

(The earlier retro PIL pixel-art look is now only a code fallback and isn't
separately capturable, so it's not archived here.)
